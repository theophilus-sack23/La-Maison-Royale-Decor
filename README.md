# La Maison Royale Décor

Website for La Maison Royale Décor — interior design, custom furniture and complete home furnishing in Accra, Ghana. Built with TanStack Start, React, TypeScript and Tailwind CSS.

## Development

You need Node.js and npm (or Bun).

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
